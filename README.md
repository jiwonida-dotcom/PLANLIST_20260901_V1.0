# U+유모바일 가입신청서 S-02 요금제 선택

## 1. 프로젝트 목적
U+유모바일 가입신청서의 요금제 선택 화면(S-02) UX 개선 프로젝트입니다.

현재 산출물은 `index.html` 단일 HTML 통합 리포트이며 **6개 탭**을 포함합니다.

1. 프로토타입 (`rt-proto`)
2. 화면설계 (`rt-spec`)
3. 기능정의 (`rt-func`)
4. 요구사항 정의서 (`rt-req`)
5. 테스트 케이스 (`rt-tc`)
6. 변경 이력 (`rt-log`)

배포: https://jiwonida-dotcom.github.io/PLANLIST_20260901_V1.0/

## 3. 이 저장소의 운영 원칙
단순 HTML 산출물 저장소가 아니라 **AI가 프로젝트를 이어서 작업하기 위한 Project Knowledge 저장소**로 운영합니다.

| 파일 | 역할 |
|---|---|
| `CLAUDE.md` | AI 세션의 작업 규칙과 컨텍스트 진입점 |
| `HANDOFF.md` | 새 세션에서 가장 먼저 읽는 현재 상태 요약 |
| `docs/` | 프로젝트 지식의 세부 문서 |
| `index.html` | 통합 리포트 / 프로토타입 |
| `Storage/` | 구 버전 보관 |
| `push.cmd` · `push.ps1` | 커밋 · 배포 |

## 4. Source of Truth 원칙
HTML은 **표현(View)** 이며, 의사결정과 작업 상태는 문서 계층에서 관리합니다.

`docs/`에서 관리하는 것 — 프로젝트 맥락 · 현재 상태 · 의사결정 · 요구사항 · 근거 · AI/개발 제약 · 마크업 규약 · 검증 · 변경 이력 · 다음 작업 · 추적성.

확정 요구사항(`C-nn`)의 **정의 원본은 `index.html`의 04 요구사항 정의서 탭**이고, `docs/REQUIREMENTS.md` 3절에 **전문 사본**이 있습니다. 불일치 시 HTML이 우선입니다.

## 5. 배포

```
push.cmd                          기본 메시지로 커밋 후 push
.\push.ps1 "docs(04): 변경 내용"    메시지 지정
```

`push.ps1`은 **원격 주소 대조·정정** → `.git` 잠금 파일 정리 → `git add -A` → 커밋 → push → **원격과 실제 대조** 순으로 동작하고, GitHub Pages가 1~2분 내 자동 배포합니다.

> 2026-08-31 저장소가 `PLANLIST_20260901_V1.0`으로 바뀌었습니다. 로컬 `origin`이 옛 저장소를 가리키면 push는 성공하지만 배포 화면은 바뀌지 않으므로, `push.ps1`이 실행할 때마다 원격 주소를 확인해 자동으로 바로잡습니다.

> `git add -A`를 쓰므로 **작업 폴더에 임시 파일을 남기지 마세요.** 제외 대상은 `.gitignore`에 정의되어 있습니다.
